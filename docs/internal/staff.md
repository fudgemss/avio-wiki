## Servers not showing up in dashboard

1. Go to any page on the website or dashboard (aviobot.app, dashboard.aviobot.app)
2. Click the profile button on the top right of the navbar
3. Select logout
4. Now click the login button which has replaced your profile picture on the navbar
5. Log back in
6. Visit the dashboard and your servers will be visible again

If the servers are still not visible to the user, they may have the incorrect permissions.
Use the following steps to identify if they have the correct permissions:

1. Ask them to check if their role in their server has the Discord Administrator Permission
2. Ask them to check if their server owner has added them as a trusted user or flight manager

If no of the above are true, and they are not the server owner, then they cannot access the dashboard and will need to sort it with their server owner.

!!! warning "Reminder: Differing permissions with dashboard access"
    As a reminder, those added as a flight manager can only access the flight planner, flights, and bookings tab on the dashboard.
    All other pages are locked behind the trusted admin permission.
